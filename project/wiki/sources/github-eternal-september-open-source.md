Claim: GitHub says generative AI has made pull requests, issues, and security reports cheap to produce at scale while human review remains expensive. It describes maintainers responding with interaction limits, invitation-only workflows, reputation signals, criteria-based gates, and automated triage. Keeper for the “Eternal September” newsroom idea: an infiltrated discussion circle grows access-control organs to keep functioning.
