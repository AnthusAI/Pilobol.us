# LLM-assisted deanonymization as a mass-scale privacy attack (Cloud Security Alliance)

- Link: https://labs.cloudsecurityalliance.org/research/csa-research-note-llm-deanonymization-privacy-20260307-csa-s/
- Outlet: Cloud Security Alliance research note
- Date: 2026-03
- Seen: 2026-09-09
- Kind: secondary / analysis

Claim: Reading of the Lermen/Paleka work with the number that matters for the house: roughly **one to four dollars per target** marginal cost, 67% recall at 90% precision, replicating in minutes what took a dedicated human investigator hours. Conclusion drawn: pseudonymous accounts and anonymized datasets should be treated as presumptively re-identifiable.

House value: the price. This is the figure the whole price-of-knowing chain lands on — what it costs now to do what once took a newsroom.
