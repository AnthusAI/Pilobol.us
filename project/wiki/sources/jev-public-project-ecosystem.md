# Jev in the Wild: A Data-Driven Analysis of the Jev Model's Functionality, Applications and Ecosystem

- Link: https://arxiv.org/html/2609.30216v1
- Authors: Guoming Ling, Muen Xue, Zijian Ye
- Submitted: 2026-09-24
- Seen: 2026-09-28
- Kind: primary preprint / public repository census

Reports 2,170 verified public GitHub projects as of September 22, including
1,865 newly created repositories after launch and 305 existing repositories
integrating Jev. Verification/annotation used model agents and repository
materials. Supports rapid public ecosystem growth, not a census of production
deployments, usage volume, customers or harm. Private/commercial applications
outside the public repository set are excluded.
