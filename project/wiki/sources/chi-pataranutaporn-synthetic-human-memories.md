# Synthetic Human Memories: AI-Edited Images and Videos Can Implant False Memories (CHI ’25)

- Link: https://doi.org/10.1145/3706598.3713697
- PDF: https://bpb-us-e2.wpmucdn.com/faculty.sites.uci.edu/dist/c/571/files/2025/08/Pataranutaporn_SyntheticHumanMemorieschi2025.pdf
- Outlet: ACM CHI ’25 (Yokohama); Pataranutaporn, Archiwaranguprok, Chan, Loftus, Maes
- Date: 2025-04 (CHI Apr 26–May 1, 2025)
- Seen: 2026-09-08
- Kind: primary study

Claim: Pre-registered N=200 (4×50). Baseline 24 images → filler → control / AI-edited images / AI-video of originals / AI-video of AI-edits. AI-edited images ↑ false recollections ~1.67× vs control; AI-videos of AI-edited images strongest (~2.05× false memories; ~1.19× confidence in those false memories). People-edits highest absolute false-memory share (~45.3% of reported memories in strongest condition). Notes TikTok trend of animating deceased relatives’ photos into simulated interactions; automatic phone filters that drop bystanders without keeping originals. Labels saying “AI-enhanced” did not stop implantation. Externalized album + AI edit = memory that prefers the copy.
